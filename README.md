# Criptografía y Seguridad

Este repositorio contiene los ejercicios, prácticas y proyectos de la asignatura de **Criptografía y Seguridad** de la **Facultad de Ciencias** de la **Universidad Nacional Autónoma de México (UNAM)**.

## Descripción

El repositorio está estructurado por tareas (como `T1`, `T2`) e incluye implementaciones en Python orientadas a la seguridad informática y la criptografía. Entre los temas desarrollados se encuentran:

* Algoritmos de cifrado simétrico (como la implementación de DES).
* Ataques de diccionario y fuerza bruta.
* Simulaciones de ataques de cumpleaños (Birthday attacks).
* Análisis de algoritmos criptográficos.

## Entorno de Trabajo

Los scripts y simulaciones están desarrollados en Python y diseñados para ejecutarse preferentemente en entornos de sistemas basados en Linux.
